# Introduction
This project showcases how Microsoft Excel can be leveraged to perform comprehensive data analysis and visualization. Using Excel’s analytical features, the project demonstrates the complete workflow — from data cleaning and transformation to insight generation through charts, pivot tables, and dashboards.

# Objectives
- Clean and preprocess raw datasets for structured analysis

- Perform exploratory data analysis (EDA) using Excel functions and tools

- Create interactive visualizations and dashboards for better decision-making

- Derive actionable business insights from real-world data

# Tools & Techniques
**Software:** Microsoft Excel

**Excel Features Used:**
- Data Cleaning (Remove Duplicates, Text to Columns)
- Pivot Tables & Pivot Charts
- Statistical & Logical Functions
- Dashboard Creation

# Key Insights
- Identified trends and seasonal patterns using Pivot Charts
- Built a summary dashboard to track KPIs
- Enhanced data clarity by removing inconsistencies and duplicates
- Improved reporting efficiency through automated Excel functions

- Women are more likely to buy compared to men (~65%).
- Maharashtra, Karnataka, and Uttar Pradesh are the top three states contributing to sales.
- The adult age group (30–49 years) contributes the most (~50%).
- Amazon, Flipkart, and Myntra are the major contributing sales channels.

# Conclusion
This project demonstrates how Excel can transform raw data into actionable insights through effective cleaning, analysis, and visualization. It showcases Excel’s strength as a powerful and accessible tool for real-world data analysis and decision-making.
